GET /api/v1/orders/{orderId}
============================

Purpose: fetch order details (items, status, totals, attempts, expiresAt).


REQUEST — existing order
------------------------
GET /api/v1/orders/9c1a2b3d-4e5f-6789-abcd-ef0123456789 HTTP/1.1
Host: localhost:8080
Accept: application/json

curl:
  curl -i http://localhost:8080/api/v1/orders/9c1a2b3d-4e5f-6789-abcd-ef0123456789
