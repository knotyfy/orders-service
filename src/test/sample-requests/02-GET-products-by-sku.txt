GET /api/v1/products/{sku}
==========================

Purpose: catalog price and current stock (use this to prove decrement/restock).


REQUEST — known SKU
-------------------
GET /api/v1/products/WIDGET-10 HTTP/1.1
Host: localhost:8080
Accept: application/json

curl:
  curl -i http://localhost:8080/api/v1/products/WIDGET-10


RESPONSE 200
------------
HTTP/1.1 200 OK
Content-Type: application/json

{
  "sku": "WIDGET-10",
  "name": "Ten-stock widget",
  "unitPrice": 5.00,
  "currency": "USD",
  "stock": 10
}


REQUEST — unknown SKU
---------------------
GET /api/v1/products/NO-SUCH-SKU HTTP/1.1
Host: localhost:8080
Accept: application/json

curl:
  curl -i http://localhost:8080/api/v1/products/NO-SUCH-SKU


RESPONSE 404 PRODUCT_NOT_FOUND
------------------------------
HTTP/1.1 404 Not Found
Content-Type: application/problem+json

{
  "type": "urn:orders:error:PRODUCT_NOT_FOUND",
  "title": "PRODUCT_NOT_FOUND",
  "status": 404,
  "detail": "Product not found",
  "code": "PRODUCT_NOT_FOUND"
}
